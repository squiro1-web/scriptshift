# ScriptShift

AI-powered transcription for old Scots handwriting — family letters, parish records, ledgers.

## What it is
A web app where a user photographs or uploads a page of old handwriting and the system transcribes it into clean, searchable text, flags uncertain words, and lets them correct with one tap. Over time it learns that family's quirks, so the next page is faster.

## Build stages
1. **Stage 1 — Core transcription**: Simple upload page wired to an existing handwriting recognition model. No training from scratch. Usable on its own.
2. **Stage 2 — Correction layer**: User fixes become training signal. One-tap corrections on flagged words.
3. **Stage 3 — Search**: Full-text search across everything a user has uploaded. Personal archive that actually gets used.

Each stage is a months-long build, not a weekend — but each is shippable independently.

## Money model
- **Free tier**: A couple of scans to hook people.
- **Subscription**: Around five pounds a month for heavier uploaders. This is the payslip.
- **Societies / archives**: Later, a per-archive fee for genealogy societies or small archives who want it for their collections. This is the upside.

## Outcome target
A growing personal archive people return to, plus a public demo page that shows the magic in one click. Distribution starts on Reddit and family-history Facebook groups — not inside Ancestry or Findmypast, which guard their users.

## Why this lane
Scottish archives like the National Records of Scotland have millions of digitized pages but almost no transcription layer. Batch-processing those and offering corrected transcripts back is a second, bigger play on top of the consumer tool.
